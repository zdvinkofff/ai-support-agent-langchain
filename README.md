# AI Support Agent (Интеллектуальный агент техподдержки на LangChain и FAISS)

Высокопроизводительное ИИ-решение для автоматизации работы первой линии технической поддержки бизнеса, реализованное на базе архитектуры **RAG (Retrieval-Augmented Generation)** с использованием современного синтаксиса **LangChain LCEL**.

Проект решает ключевую бизнес-проблему — рутинную нагрузку на операторов поддержки, заменяя их интеллектуальным агентом, способным осуществлять смысловой (семантический) поиск по внутренним базам знаний компании за миллисекунды.

---

## 🛠 Технологический стек и архитектура

*   **ИТ-Агенты и Оркестрация:** LangChain (пайплайны `RunnablePassthrough`, `StrOutputParser`).
*   **Векторная база данных (Vector Store):** FAISS (Facebook AI Similarity Search) для хранения эмбеддингов высокой размерности.
*   **Обработка данных:** Слой векторного поиска (`retriever`), обеспечивающий извлечение топ-K наиболее релевантных контекстов.
*   **Пайплайн разработки:** Python, Jupyter Notebook, Pandas, NumPy.

---

## 🚀 Инженерные решения и логика работы:

1. **Семантический векторный поиск:** В отличие от классического поиска по ключевым словам, система понимает синонимы и контекст вопроса. Фраза клиента *"заглючил роутер, как скинуть"* безошибочно сопоставляется с инструкцией *"перезагружается зажатием кнопки Reset"*.
2. **Архитектура LCEL (LangChain Expression Language):** Цепочка спроектирована с использованием современных стандартов декларативного связывания компонентов через оператор `|`.
3. **Безопасность инференса:** Промпт жестко ограничивает рамки поведения ИИ, запрещая галлюцинации (придумывание фактов вне контекста базы знаний).

## 📦 Инструкция по локальному развертыванию

1. Клонировать репозиторий:
```bash
git clone https://github.com
cd ai-support-agent-langchain
```
2. Установить современные ИИ-библиотеки:
```bash
pip install langchain langchain-community faiss-cpu notebook pandas numpy
```
3. Запустить среду разработки и открыть ноутбук:
```bash
jupyter notebook ai_support_agent_langchain.ipynb
```
